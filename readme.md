城市更新中集体行动力的影响机制研究 —— 以北京市老旧小区电梯加装为例
Collective Action Capacity in Urban Renewal: A Case Study of Elevator Installation in Old Residential Communities in Beijing

本项目为论文 《城市更新中集体行动力的影响机制研究 —— 以北京市老旧小区电梯加装为例》 的配套代码与数据仓库，包含论文原文、爬虫代码、电梯加装原始数据。
📌 项目简介
城市存量更新背景下，老旧小区电梯加装是典型集体行动场景。本研究以北京市老旧小区为对象，整合 UTAUT 框架 + 社会资本理论，构建 “集体行动需求 - 集体行动能力 - 集体社会资本 - 便利条件” 影响框架，实证揭示社区集体行动力的形成机制。
核心结论
15 分钟步行圈绿地面积：显著正向促进集体行动力，是培育社会资本的关键载体。
社会身份分散度：影响呈双重性 ——同质化易凝聚共识、异质性利于资源互补。
年龄结构：中年人口占比正向驱动；老年人口占比高社区呈现高需求、低能力困境。
三大维度：集体行动需求、能力、社会资本均显著影响集体行动力，部分变量存在模型异质性。

📊 数据说明
北京市住建委电梯加装数据：含小区地址、楼栋层数、建成年代、加装状态、适宜性判定等，共 150210 条原始记录。
空间匹配：进行地理编码后地址与具体坐标匹配数据（有偏）
核心被解释变量：电梯加装指数（已加装 / 适宜加装单元占比加权）。


🛠️ 技术栈
爬虫：Python + Playwright（动态页面爬取）
地理匹配：百度地图 API（地址→经纬度）
空间分析：缓冲区匹配、空间聚合
实证模型：两阶段零膨胀回归、Tweedie 回归（适配高零值 + 右拖尾数据）
