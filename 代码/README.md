# 北京电梯数据爬虫工具
这是一个用于爬取北京政府网站加装电梯相关数据的自动化工具，通过分级爬取逻辑获取区域、街道、电梯项目详情及表格数据，支持自动保存、异常日志记录和断点续爬能力。

## 核心功能
1. `get_disclass.py` - 爬取北京市各区及对应街道的分类URL，生成区域-街道URL映射表
2. `get_url_of_build.py` - 基于区域-街道URL，批量获取各电梯项目的标题、地址和详情页URL
3. `get_table.py` - 解析电梯项目详情页，提取表格形式的核心信息（如审批信息、施工详情等）
4. 辅助模块：`config.py`（统一配置）、`log.py`（日志记录）、`SAVE_AND_CHECK.py`（数据保存与校验）

## 配置说明
所有可配置参数集中在`config.py`文件，无需修改核心代码即可适配需求：
- 路径配置：数据存储、日志保存、输入输出文件的默认路径
- 时间配置：页面加载等待时间、随机延迟范围、重试等待时长
- 爬取配置：临时保存阈值（避免数据丢失）、User-Agent池（模拟多浏览器访问）
- 目标配置：政府网站电梯数据首页URL

## 使用步骤
1. 安装依赖：执行 `pip install -r requirements.txt`，安装playwright等核心依赖
2. 初始化浏览器：执行 `playwright install chromium`，安装Chrome内核（爬取核心依赖）
3. 分级运行脚本（按顺序执行）：
   - 第一步：运行 `python get_disclass.py`，获取区域-街道分类URL
   - 第二步：运行 `python get_url_of_build.py`，获取所有电梯项目详情页URL
   - 第三步：运行 `python get_table.py`，提取详情页表格数据并保存
4. 查看结果：数据文件和日志自动保存到`北京电梯数据库`目录下

## 注意事项
1. 脚本默认以可视化模式运行（显示浏览器窗口），便于调试；生产环境可修改`launch(headless=True)`隐藏窗口
2. 内置随机等待和User-Agent轮换机制，降低被识别为爬虫的风险
3. 支持临时保存功能，每爬取200条数据自动备份，异常中断时保留已爬取结果
4. 运行过程中生成4类日志：运行日志、保存日志、URL访问警告、内容提取警告，便于问题排查
5. 若遇到iframe加载失败、按钮点击无效等问题，可调整`config.py`中的等待时间参数

## 输出文件说明
- 分类URL结果：`北京电梯数据库/classify_in_street.json`（区域-街道URL映射）
- 项目列表数据：`北京电梯数据库/url地址/电梯数据_社区_all.json`（含标题、地址、详情URL）
- 表格详情数据：`北京电梯数据库/conanda/succeed.json`（最终提取的核心表格数据）
- 临时备份文件：`北京电梯数据库/conanda/succeed_*.json`（按阈值生成的临时备份）
- 日志文件：`北京电梯数据库/warnings_and_log`目录下（按日期分类的运行日志和警告日志）
